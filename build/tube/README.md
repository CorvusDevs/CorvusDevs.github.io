# Tube Ambient Lights launch page

Run `python3 build/build-tube.py` from the repository root. Commit generated
landing pages together with the template, copy, configuration and assets. The
other product pages, localized support/privacy pages and their URLs are not
generated by this command. Run with `--check` to verify generated HTML.

- The comparative images are genuine matched iPad captures of Big Buck Bunny
  with the effect off/on. The opening aurora composition is illustrative and
  labeled accordingly. Do not present it as an app screenshot.
- English and the two Spanish editions use dedicated marketing copy. Other
  editions use native marketing snippets and the reviewed iPhone/iPad App Store
  copy for controls and limits, with the same layout and interactive demo.
- Mac is shown up front and in the download section. Its listing link and hardware
  requirements are evergreen, with no claim that the native Mac version is already
  on sale. Do not derive native Mac availability from the listing’s iPad
  compatibility footnote. No website edit is needed to keep the Mac section or
  its download destination after release. The homepage catalog currently lists
  the platforms already confirmed on sale.
