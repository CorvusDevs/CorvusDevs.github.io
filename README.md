## How we build

- No accounts or telemetry for core features
- Native experiences for Mac, iPhone, iPad, and Safari
- Free tools and one-time purchases for focused jobs
- Human support by email

The website catalog is generated from [`apps.json`](https://github.com/CorvusDevs/CorvusDevs.github.io/blob/main/apps.json), which supplies product identity, grouping, platforms, pricing, links, and screenshots to the main page and its localized versions.
