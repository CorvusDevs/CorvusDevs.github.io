Kebijakan privasi Tube Ambient Lights for Safari

Diperbarui 11 November 2026. Kebijakan ini menjelaskan adaptasi Safari saat ini, bukan ekstensi browser asalnya.

Pemrosesan video dan izin

Tube Ambient Lights for Safari memproses warna video yang sedang diputar secara lokal di perangkat Anda untuk menghasilkan pencahayaan ambien. Mulai otomatis dipilih secara bawaan, tetapi hanya berjalan setelah Anda mengaktifkan ekstensi dan memberikan akses ke situs YouTube yang didukung, https://www.youtube.com/* dan https://m.youtube.com/*. Tidak ada permintaan izin yang terbuka otomatis dan tidak ada akses situs web yang diberikan otomatis. Pilihan sebelumnya untuk menonaktifkan mulai otomatis dipertahankan. Mulai secara manual berlaku untuk tab YouTube yang didukung yang Anda pilih. Mulai otomatis hanya menggunakan izin host yang telah Anda berikan. Anda dapat menonaktifkan mulai otomatis di pengaturan ekstensi, menghentikan cahaya saat ini dari pop-up, serta mengelola atau mencabut akses situs web di pengaturan ekstensi Safari.

Ekstensi membaca URL halaman terpilih dan ID video agar tindakan dan pengaturan tetap terkait dengan tab dan video yang dituju. Ekstensi membaca status pemutar dan dimensi video untuk merender pencahayaan dan menyediakan diagnostik lokal. Ekstensi tidak mengirim detail tersebut, bingkai video, atau warna kepada pengembang maupun layanan analitik atau pelaporan kerusakan.

YouTube tetap menyediakan halaman dan medianya sendiri, dan tautan yang Anda pilih untuk dibuka ditangani oleh layanan tujuan sesuai kebijakan privasi masing-masing.

Pengaturan yang disimpan secara lokal

Ekstensi menyimpan pengaturan, prasetel, preferensi mulai otomatis, dan draf pengaturan yang belum selesai menggunakan penyimpanan ekstensi lokal browser. Aplikasi pendamping menyimpan preferensi pengenalan dan antarmukanya sendiri di perangkat Anda. Aplikasi menggunakan UserDefaults untuk preferensinya sendiri, bukan untuk membaca informasi aplikasi lain. Pengaturan ini tidak disinkronkan melalui server pengembang.

Pengaturan tetap tersimpan secara lokal hingga diubah atau data tersimpan aplikasi/browser terkait dihapus. Menonaktifkan akses situs web menghentikan akses halaman yang diizinkan; tindakan ini sendiri tidak menghapus preferensi atau file yang telah Anda ekspor.

Diagnostik dan file yang Anda pilih untuk diekspor

Aplikasi tidak mengirim laporan kerusakan secara otomatis. Tidak ada pelaporan Sentry, analitik pengembang, atau layanan pelacakan dalam adaptasi ini.

Jika Anda membuka laporan diagnostik lokal, laporan dapat memuat URL halaman saat ini dan ID video, build aplikasi, dimensi video dan posisi/status pemutaran, informasi perender dan performa, pengaturan, serta pesan kesalahan terbaru. Kesalahan terbaru disimpan dalam daftar di memori dengan ukuran terbatas; teks URL dihapus dari pesan kesalahan tersebut, tetapi laporan diagnostik memiliki kolom URL dan ID video tersendiri.

Anda dapat memeriksa laporan sebelum menyimpan atau membagikannya. Ekspor diagnostik dan pengaturan berupa file yang Anda pilih untuk disimpan secara lokal. Aplikasi tidak mengunggahnya atau mengirimkannya kepada dukungan. Jika Anda memilih membagikan file menggunakan aplikasi lain, periksa isinya dan hapus apa pun yang tidak ingin dilihat penerima. File tersimpan tetap ada hingga Anda menghapusnya menggunakan Finder, File, atau pengelola file pilihan Anda, termasuk salinan yang telah Anda buat.

Pengumpulan data dan kontak

Pengembang tidak menerima riwayat penelusuran, detail video, pengaturan, atau file diagnostik melalui aplikasi. Tidak ada akun pengembang, pengenal iklan, atau fitur pelacakan lintas aplikasi. Karena aplikasi ini tidak mengirim data tersebut kepada pengembang, tidak ada salinan yang disimpan pengembang untuk dihapus oleh aplikasi.

Untuk pertanyaan privasi atau dukungan, Anda dapat mengirim email ke corvusdevs@outlook.com menggunakan aplikasi email Anda sendiri. Informasi apa pun yang Anda pilih untuk disertakan akan dibagikan kepada penerima tersebut melalui penyedia email Anda. Sertakan hanya yang diperlukan untuk pertanyaan Anda; jangan kirim kata sandi atau token akun.
